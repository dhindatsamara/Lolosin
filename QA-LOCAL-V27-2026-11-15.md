### 4. Perbaikan tombol share — resolve instan tidak pernah "Dibagikan"
Heuristik waktu di `lib/share.ts` + `lib/shareCard.ts`:
`navigator.share()` yang resolve < 800 ms dianggap no-op
(sheet tidak pernah tampil, pola Brave/Chrome tertentu) dan
otomatis fallback (foto: unduh PNG; teks: salin clipboard);
`canShare` dibungkus try/catch; AbortError diam; gagal lain
fallback unduh; iOS (tanpa atribut download) buka PNG di tab
baru dengan hasil 'opened'. QA §19j (22 cek, semua skenario
mock): foto + teks resolve instan → fallback terjadi
("Foto tersimpan" / "Tautan disalin", clipboard terisi teks
berbagi) dan "Dibagikan" TIDAK PERNAH tampil; resolve lambat
(1000 ms) → "Dibagikan" tanpa fallback; canShare melempar →
0 pageerror/console error baru, share tetap dicoba, fallback
jalan; AbortError → diam tanpa pesan/download; error lain →
fallback unduh; iOS → window.open dengan blob URL + pesan
"Foto dibuka di tab baru, simpan manual dari sana"; desktop →
PNG 1080x1350 terunduh (262.255 byte) + "Foto tersimpan".
Verifikasi visual PNG hasil unduh: maskot Osi (topi wisuda)
ter-render benar di lingkaran putih, pil "Teman Baru", "0 hari",
Level 1 / 0 XP, footer lolosin.netlify.app. File: share.ts,
shareCard.ts, PetCard.tsx (feedback sudah ada, tidak berubah).
